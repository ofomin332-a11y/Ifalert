# Тривога ІФ | Моніторинг

Railway worker: отримує активні записи через API alerts.in.ua і фільтрує точним UID Івано-Франківської області (13). Надсилає нові записи й зміни поля threats.

## Railway Variables
- `TELEGRAM_BOT_TOKEN` — новий токен BotFather
- `TELEGRAM_CHAT_ID` — ID Telegram-групи
- `ALERTS_API_TOKEN` — персональний токен alerts.in.ua
- `POLL_SECONDS` — за замовчуванням 10 секунд (6 запитів/хв)

## Встановлення
Завантажте файли в GitHub → Railway → Deploy from GitHub Repo → додайте змінні → перевірте логи на `Baseline established`.

## Обмеження
- Перший запит встановлює базовий стан без пересилання старих тривог.
- HTTP 304 не трактують як відбій; помилка API не очищає попередній стан.
- Зникнення запису з активного списку надсилається як оновлення статусу API, а не як самостійне підтвердження відбою.
- API має ліміти запитів; не зменшуйте інтервал без перевірки актуальних правил.
- API може містити тип загрози, але не обов'язково точний напрямок/траєкторію. Бот не вигадує таку інформацію.
- Ця версія не читає сторонні Telegram-канали; для них потрібна окрема інтеграція з дозволеним доступом.
- Дедуплікація є в межах одного процесу; для збереження стану після рестарту Railway потрібне постійне сховище.
- Бот додатковий, не замінює сирени та офіційні сповіщення.
